十三个 Facebook 账号：评论 AI 接口配置与评论界面采集

本地免费模型方案请优先阅读 本地评论AI说明.txt，使用 setup-local，无需 OpenAI 密钥或充值。
本说明第二至四节保留为可选 OpenAI 配置流程；第五节的评论界面采集同样适用于本地 AI。

当前包完成两项准备：AI 密钥本机加密保存和回复草稿测试；真实评论界面的录制与采集。
自动读取评论、自动发送、去重及轮询任务尚未实现或启用，安装本包不会发送 Facebook 评论。
本包只更新 comment_ai.py、record_comment_flow.py 和本说明，不替换上传程序、账号配置或视频。

一、目标工作流（后续接入发送程序）
覆盖 fb01～fb13，按各自已登记身份处理自己视频的评论。
新评论 → 检查评论编号及是否已回复 → 按评论语言生成简短回复 → 发送 → 核对结果并记录。
只在购买咨询时提供已确认的亚马逊链接，不为普通评论统一插入广告。
跳过垃圾评论及自己的评论；无法从已知文案回答的事实问题留待核对，不编造价格、库存或承诺。
同一评论只回复一次；发送结果不明保留待核对，不立即重复发送。
当前 AI 模块只读取文案和评论，不分析视频画面或声音。

二、开通 OpenAI API
访问 https://platform.openai.com/ 创建或登录账号，在 API Billing 开通可用额度。
在 https://platform.openai.com/api-keys 创建 API 密钥。
API 用量与 ChatGPT 订阅分开计费；本包 check 会产生一次 API 调用用量。
默认模型为 gpt-4.1-mini；实际可用模型以项目为准，可在 comment_ai_config.json 的 model 中调整。
不要把密钥发到聊天，也不要放进视频文案、录制代码或截图。

三、在 Windows 本机配置密钥（图形窗口）
先关闭之前等待输入密钥的黑色配置窗口。解压本包到 E:\FB-AutoUpload，在 PowerShell 单独执行：
& E:\FB-AutoUpload\.venv\Scripts\python.exe E:\FB-AutoUpload\comment_ai.py setup --gui

会打开“Facebook 评论 AI：密钥配置”窗口，提供遮挡输入框、“粘贴密钥”、“保存并加密”和“取消”按钮。
先打开这个窗口，再回 API Keys 页面复制完整密钥，最后回配置窗口点“粘贴密钥”。
不要先复制密钥再复制安装命令，否则剪贴板会被命令覆盖。
密钥只显示为星号和字符数量，不提供显示明文按钮。请点击“保存并加密”。
如果复制的是命令、空格、引号或省略号遮挡后的密钥，窗口会提示重新复制，不会退出到命令行。
若 API Keys 列表只显示部分密钥，不能用该显示文字配置；需要新建后在创建弹窗中复制完整值。
保存成功后窗口关闭，原 PowerShell 显示“密钥已使用当前 Windows 用户加密保存”。
若提示无法打开窗口，请检查 Python 的 Tcl/Tk 安装组件；不会降级为可回显的输入方式。
若密钥曾被粘贴成普通 CMD 命令或出现在截图中，建议先撤销旧密钥、重新创建，并关闭旧窗口。
工具使用当前 Windows 用户的 DPAPI 加密，校验加解密后保存到 .secrets\comment_ai.dpapi。
已有加密密钥与配置会先备份；不会写入明文密钥，不更改十三个 Facebook 登录资料。
换 Windows 用户或电脑后通常需要重新配置。不要上传 .secrets 或备份中的密钥文件。

四、测试一次 AI 回复（只显示草稿，不发送）
& E:\FB-AutoUpload\.venv\Scripts\python.exe E:\FB-AutoUpload\comment_ai.py check --caption-file E:\FB-AutoUpload\common_caption_today.txt --comment "Where can I buy this book?"

action=reply 表示可供后续程序采用的草稿；review 表示需要核对；skip 表示无需回复。
HTTP 401：检查密钥和项目权限；429：检查 API 可用额度及频率；404：检查模型可用性。
连接失败：检查本机到 OpenAI API 的连接。只发送错误信息或截图，不发送密钥。

五、采集真实评论界面（无需 AI 密钥，可独立进行）
十三个账号混合了个人主页和公共主页，需要各采集一份实际评论操作。
先关闭对应账号手动打开的 Chrome 窗口，并确认没有上传任务运行。
先采集公共主页 fb12（Prycken June），在 PowerShell 单独执行：
& E:\FB-AutoUpload\.venv\Scripts\python.exe E:\FB-AutoUpload\record_comment_flow.py --account fb12

程序检查原浏览器资料中的登录身份后打开 Playwright Inspector。
在 Inspector 点 Record，手动打开自己的一条有真实评论的视频，展开评论，点一条评论的 Reply。
展开回复输入框即可，可输入测试文字但不要点发送。保持评论区和回复框展开，点 Inspector 的 Resume。
工具自动保存页面结构 comments.aria.txt、截图 comments.png、账号上下文 context.json。
保存位置显示在终端：E:\FB-AutoUpload\logs\comment-recordings\fb12-时间戳。
也可把 Inspector 中的录制代码复制另存为 recorded_fb12_comments.py。

完成并退出第一个录制窗口后，再采集个人主页 fb03（Lisa Mills）：
& E:\FB-AutoUpload\.venv\Scripts\python.exe E:\FB-AutoUpload\record_comment_flow.py --account fb03

把这两个采集文件夹里的 comments.aria.txt、context.json 和截图提供给适配人员。
登录或验证页面、可见密码输入框及其他网站不会采集；不导出 Cookie、密码或浏览器资料。
正常登录在录制前完成，避免把登录操作放进手动录制代码。
